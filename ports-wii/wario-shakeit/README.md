# Wario Land: Shake It!

Port da edição Wii norte-americana, com a mira corrigida e perfil X3. Use os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `wario-shakeit/gamedata/`. Use a imagem do disco americano RWLE01, revisão 0, em um dos formatos descritos no guia.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

O perfil X3 é a edição com cadência mais leve. Consulte o guia para ajustar o perfil de vídeo.

- [Instruções e requisitos / Installation and requirements](INSTALLATION.md)
- [Comunidade NextOS](https://discord.gg/DHfY62eDNN)

Extract the port ZIP into your device’s ports directory. Place your own game files in `wario-shakeit/gamedata/` and launch the port. See the [installation instructions](INSTALLATION.md) for the supported editions and formats.
