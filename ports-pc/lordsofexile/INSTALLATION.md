# Lords of Exile – instalação / installation

Use o guia abaixo da versão 1.3.13. The port ships with this guide in `gamedata/README.txt`.

~~~text
Lords of Exile - put your own copy of the game here / coloque aqui a sua copia do jogo

Either ONE of these / UM dos dois:

1. The GOG installer / o instalador GOG:
       setup_lords_of_exile_1.0.0c_(75105).exe
   (any single .exe in this folder is taken as the installer; keep only one)
   (qualquer .exe sozinho nesta pasta e tratado como o instalador; deixe so um)

2. The files of an installed Windows copy, v1.0.0c (GOG or Steam), loose in this folder:
   Os arquivos de uma instalacao Windows, v1.0.0c (GOG ou Steam), soltos nesta pasta:
       data.win
       audiogroup1.dat audiogroup2.dat audiogroup4.dat audiogroup5.dat
       audiogroup6.dat audiogroup7.dat audiogroup8.dat audiogroup9.dat
       game_credits_file.csv multi_language_file.csv options.ini

Then open "Lords of Exile". The first opening prepares the data and takes a few minutes
with a black screen. This package does not contain the game. Keep your original.
Depois abra "Lords of Exile". A primeira abertura prepara os dados e leva alguns minutos
com a tela preta. Este pacote nao contem o jogo. Guarde o seu original.
~~~
