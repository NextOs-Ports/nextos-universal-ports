# Lords of Exile

Port da edição Windows para Linux ARM64. O ZIP requer os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `lordsofexile/gamedata/`. Use os arquivos originais da edição Windows. O guia explica a preparação para cada loja.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

A versão 1.3.13 mantém o runtime da versão anterior e corrige o lançador. O novo lançador foi validado no PC.

## English

Extract the port ZIP into your device’s ports directory. Place your own game files in `lordsofexile/gamedata/` and launch the port. See the [installation instructions](INSTALLATION.md) for the supported editions and formats.
