# Shakedown: Hawaii

Port da edição iOS de Shakedown: Hawaii. Use os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `shakedown-ios/gamedata/`. Use o IPA original da edição iOS 1.0.2.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

A abertura da versão 1.0.2 foi validada no caminho gráfico Mali do NextOS.

- [Instruções e requisitos / Installation and requirements](INSTALLATION.md)
- [Comunidade NextOS](https://discord.gg/DHfY62eDNN)

## English

Extract the port ZIP into your device’s ports directory. Place your own game files in `shakedown-ios/gamedata/` and launch the port. See the [installation instructions](INSTALLATION.md) for the supported editions and formats.
