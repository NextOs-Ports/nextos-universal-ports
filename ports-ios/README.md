# Ports iOS

Ports de jogos iOS: o executável original do iPhone roda num runtime próprio com a Framework V6. Você fornece o seu `.ipa` (BYO-data); nenhum pacote inclui jogo ou dados.

iOS game ports: the original iPhone executable runs on a purpose-built runtime with Framework V6. You provide your own `.ipa` (BYO-data); no package includes the game or its data.
