# Neon Drive

Port da edição iOS 1.51 (build 1.52), com controles físicos. O ZIP requer os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `neondrive/gamedata/`. Use um IPA original compatível da edição iOS.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

Testado no NextOS com Mali-450 e no R36T/K36S com dArkOS4Clone e Mali-G31.
