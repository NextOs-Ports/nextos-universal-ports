# The Legend of Zelda: The Wind Waker – instalação / installation

Use o guia abaixo da versão 0.2.34. The port ships with this guide in `gamedata/README.txt`.

~~~text
The Legend of Zelda: The Wind Waker — GameCube USA, GZLE01, revisão/revision 0

PORTUGUÊS
Copie uma única ISO completa da sua cópia original para esta pasta gamedata/.
O nome do arquivo não importa (qualquer nome terminado em .iso).
ISO já traduzida ou modificada é recusada: use a ISO original e a tradução em ZIP.
Não é a edição HD nem uma versão de outra região. Não é necessário APK ou update.
Referência testada: 1.459.978.240 bytes; SHA-256:
ec2d4ee790f48bee3d4c10feed166370df895f474e8db3f9af3b16ee001436df

Extraia o ZIP do port em Ports, coloque a ISO aqui e abra The Legend of Zelda -
The Wind Waker pelo menu. V7/NXExtract verifica e prepara data/game.iso, exibe
progresso e então abre a apresentação de 5 segundos e o jogo. O preparo completo
foi medido em 259 segundos na bancada; cartão e aparelho podem mudar esse tempo.
Dados já preparados e válidos são reaproveitados nas próximas aberturas.
Se interromper o preparo, reabra pelo mesmo launcher e siga a verificação normal;
não crie recibos nem remova os dados manualmente. Não é preciso refazer tudo ao
atualizar somente o executável.

Tradução opcional: coloque um único ZIP compatível aqui, sem extrair. Consulte
TRANSLATIONS.txt. Seus saves ficam em native-saves/; preserve essa pasta,
NEXTOSSETTINGS.txt, NEXTOSCONTROLLERS.gptk, ISO, data/ e traduções ao atualizar.
O ZIP não inclui a ISO. O runtime é Linux AArch64; a mídia original é GameCube.
A validação física desta entrega cobre somente o aparelho de bancada autorizado.
A inicialização com bibliotecas do dArkOS RG43 foi testada no PC; isso não certifica
imagem/áudio/gameplay físico em RG43V Pro nem todos os firmwares.

ENGLISH
Place exactly one complete ISO of your own original USA GameCube copy (GZLE01,
revision 0) in this gamedata/ directory. Any file name ending in .iso works. A pre-translated or
modified ISO is refused; use the original ISO plus a translation ZIP. This is not the HD edition or another
region. No APK or game update is needed. Tested size and SHA-256 appear above.
Extract the port ZIP into Ports, add the ISO, then launch The Legend of Zelda -
The Wind Waker. V7/NXExtract verifies and prepares data/game.iso, shows progress,
then starts the five-second splash and game. Complete preparation took 259 seconds
on the test handheld; actual time depends on storage and hardware. Valid prepared
data is reused. After interruption, reopen the normal launcher; never fabricate
receipts. An executable-only update does not require repeating valid preparation.
Optional translation: add one compatible ZIP without extracting; see TRANSLATIONS.txt.
Preserve native-saves/, both owner configuration files, ISO, data/ and translations
when updating. No game ISO is included. Runtime: Linux AArch64; game: GameCube.
Physical validation covers the authorized test handheld only. RG43 dArkOS library
tests on the PC do not certify physical RG43V Pro rendering, sound or gameplay.
~~~
