Como instalar
  1. Baixe o .zip do port.
  2. Copie para a pasta de ports do aparelho: ports/ (PortMaster/ArkOS) ou roms/ports (NextOS).
  3. Coloque o APK/XAPK original do jogo onde o README do port indicar (normalmente <port>/gamedata/).
  4. Abra pelo menu. A primeira abertura extrai e valida os dados.
  5. SELECT + START sai com segurança.

Dentro do app PortMaster: baixe 040_nextos.source.json e coloque em PortMaster/config/ (ao lado de 020_portmaster.source.json). Na próxima abertura o PortMaster lista estes ports.

Nenhum pacote inclui jogo ou dados de jogo. Você precisa da sua própria cópia legítima.
