# Crash Twinsanity

Port da edição de PlayStation 2. O ZIP requer os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `twinsanity/gamedata/`. Use uma ISO americana SLUS-20909 v2.00 ou europeia SLES-52568.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

Prova física no R36T/K36S com dArkOS4Clone e Mali-G31 usando o disco americano.
