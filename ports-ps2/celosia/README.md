# Shadow of the Colossus

Port nativo da edição de PlayStation 2 para Linux ARM64 com OpenGL ES 3, baseado no projeto Celosia de HenryKun55.

Extraia o ZIP na pasta `ports` e coloque uma ISO completa do seu disco americano SCUS-97472 v1.00 em `celosia/gamedata/`. A primeira abertura prepara os dados e precisa de cerca de 2,8 GB livres além da ISO.

Dois toques em Select abrem o menu NextOS. Select + Start fecha o jogo. Os cartões de memória ficam em `celosia/saves/memcards/`.

A versão 1.0.0 foi testada no R36T/K36S com dArkOS4Clone, Mali-G31 e tela de 640 × 480.

## English

Extract the ZIP into your device’s `ports` folder and place your US disc image (SCUS-97472 v1.00) in `celosia/gamedata/`. Allow about 2.8 GB of free space in addition to the ISO. Double-tap Select for the NextOS menu, or press Select + Start to quit.
