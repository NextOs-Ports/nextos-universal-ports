# AVGN I & II Deluxe

Port da edição Android 1.2.5. Use os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `avgn12deluxe/gamedata/`. Use o pacote original em um dos formatos do guia.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

O sufixo docs1 identifica a revisão do guia. O runtime é o mesmo da versão 1.0.1 aprovada.

## English

Extract the port ZIP into your device’s ports directory. Place your own game files in `avgn12deluxe/gamedata/` and launch the port. See the [installation instructions](INSTALLATION.md) for the supported editions and formats.
