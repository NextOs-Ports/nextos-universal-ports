# The Messenger

Port da edição Android de The Messenger para Linux ARM64. A versão 1.2.1 corrige a sobreposição de comandos dos controles no APK 1.2.

## Instalação

1. Extraia o ZIP para a pasta de ports do aparelho.
2. Coloque os arquivos da sua cópia em `the-messenger-android/gamedata/`. Use somente o APK original e completo da edição Android 1.2 (versionCode 1), sem splits nem OBB.
3. Abra o port pelo menu e aguarde o NXExtract. SELECT + START encerra pelo controle.

Controles e gameplay validados no R36T/K36S com dArkOS, usando dados já preparados.

[Guia completo / Full guide](INSTALLATION.md)

## English

Extract the port into Ports, then place your own complete Android 1.2 APK (versionCode 1) in `the-messenger-android/gamedata/`. Launch the port and let NXExtract prepare the files.
