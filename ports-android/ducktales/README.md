# DuckTales: Remastered

Port da edição Android de DuckTales: Remastered para Linux ARMHF. A versão 1.1.11 corrige a preparação dos dados e a busca das bibliotecas usadas pelo extrator.

## Instalação

1. Extraia o ZIP para a pasta de ports do aparelho.
2. Coloque os arquivos da sua cópia em `ducktales/gamedata/`. Use o APK original da Google Play 1.0.3 e o OBB main.124, solto ou dentro do ZIP que o contém.
3. Abra o port pelo menu e aguarde o NXExtract. SELECT + START encerra pelo controle.

Requer suporte a bibliotecas ARMHF de 32 bits no firmware.

[Guia completo / Full guide](INSTALLATION.md)

## English

Extract the port into Ports, then place your own Google Play 1.0.3 APK and main.124 OBB in `ducktales/gamedata/`. Launch the port and let NXExtract prepare the files.
