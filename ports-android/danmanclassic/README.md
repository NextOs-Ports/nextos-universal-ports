# Dan the Man Classic

Port da edição Android de Dan the Man Classic com controles físicos. Use os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `danmanclassic/gamedata/`. Use o APK/XAPK original da versão 1.14.92 para arm64-v8a.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

Testado no NextOS com Mali-450 e no R36T/K36S com dArkOS e Mali-G31.
