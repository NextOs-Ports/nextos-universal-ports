# 🤖 Ports Android

Ports de jogos Android para portáteis Linux AArch64. Cada pasta traz `README.md`
(controles, requisitos, versões) e, quando necessário, `INSTALLATION.md`. Os pacotes ficam
nas [Releases](https://github.com/NextOs-Ports/nextos-universal-ports/releases) com a tag `<jogo>-vX.Y.Z`. **Nenhum pacote inclui o jogo**:
o instalador extrai do APK/XAPK do próprio usuário.
