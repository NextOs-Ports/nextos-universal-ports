# The Binding of Isaac: Rebirth

Port da edição Android de The Binding of Isaac: Rebirth, com o motor Repentance. Use os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `isaac-android-nextos/gamedata/`. Use o APK Android completo 1.7771 (arm64-v8a).
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

Testado no NextOS/Mali-450 e no R36T/K36S com dArkOS4Clone/Mali-G31.
