# Rockman X Survivors

Port da edição Web 1.6.2 para Linux ARM64. O ZIP requer os dados da sua cópia do jogo.

## Instalação

1. Extraia o ZIP do port para a pasta de ports do aparelho.
2. Adicione os arquivos originais em `rockmanxsurvivors/gamedata/`. Use o ZIP completo da edição Web 1.6.2.
3. Abra o jogo pelo menu Ports e aguarde o NXExtract concluir o preparo.

Prova física no R36T/K36S com dArkOS4Clone e Mali-G31.
