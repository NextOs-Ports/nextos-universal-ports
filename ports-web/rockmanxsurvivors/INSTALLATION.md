# Rockman X Survivors – instalação / installation

Use o guia abaixo da versão 1.0.2. The port ships with this guide in `gamedata/README.txt`.

~~~text
Rockman X Survivors — original Web 1.6.2, Unity 6000.3.10f1
PT: copie o ZIP Web original completo para esta pasta e abra Rockman X Survivors.
O ZIP testado de referência é RockmanXSurvivors_Web_v1.6.2.zip; pode ser renomeado.
Mantenha todos os arquivos Build/*.data.unityweb e Build/*.wasm.unityweb originais.
O jogo é identificado pelo módulo e pelos oito payloads, não pelo nome/SHA do ZIP.
O NXExtract prepara no próprio aparelho, com tela e progresso; depois ocorre
a abertura NEXT OS de 5 segundos. Não precisa de PC ou comandos.
O tempo varia com o cartão; preparo válido é reaproveitado. Saves: saves/.
A cobertura física consta no recibo desta versão, sem certificação de outros aparelhos.
EN: copy the complete original Web 1.6.2 ZIP here and launch Rockman X Survivors.
Reference: RockmanXSurvivors_Web_v1.6.2.zip; renaming is accepted. Keep the original
Build/*.data.unityweb and Build/*.wasm.unityweb files. The game module and eight
payloads identify the supported build; the ZIP name/hash do not select it.
NXExtract prepares it visibly on the device; then the 5-second NEXT OS splash
and game run. No PC or terminal required. Time depends on the card; valid
preparation is reused. Saves: saves/. Device coverage is in the delivery receipt.
https://github.com/gaho727/rockmanx-survivors/releases/tag/v1.6.2
~~~
